## Kod python

```python
#!/usr/bin/env python3

from sys import stdout
from time import time

epoch_delta = 2208988800  # 1900 vs 1970
encoded_time = int(time() + epoch_delta).to_bytes(4, 'big')

stdout.buffer.write(encoded_time)
```

## Kod asm (x86\_64, Linux)

```asm
; time-service.asm — TIME protocol server (RFC 868)
section .data
    time_offset dq 2208988800  ; seconds from 1900 to 1970
section .text
    global _start
_start:
    xor edi, edi               ; tloc=NULL
    mov eax, 201               ; time() syscall
    syscall                    ; result in rax
    add rax, [time_offset]     ; add offset to get RFC868 time
    bswap eax                  ; reverse byte order
    push rax
    mov eax, 1                 ; write() syscall
    mov edi, 1                 ; fd=stdout
    mov rsi, rsp               ; buf=time value
    mov edx, 4                 ; size=4
    syscall
    mov eax, 60                ; exit() syscall
    xor edi, edi               ; rc=0
    syscall
```
<!-- .element style="font-size: 0.4em;" -->

---
## 3 syscalle + 2 operacje arytmetyczne

- `time(NULL)`
- `date = time() + time_offset`
- `bswap date`
- `write(stdout, &date, 4)`
- `exit(0)`
